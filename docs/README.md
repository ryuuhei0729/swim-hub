# docs

| ディレクトリ | 内容 |
| --- | --- |
| `specs/` | 要件定義書・機能仕様書 |
| `roadmap/` | 実装・マネタイズ等のロードマップ |
| `reviews/` | UI/UX・SEO・パフォーマンス等のレビュー/診断レポート |
| `testing/` | E2E テスト計画・仕様、手動テスト手順 (`manual-test/`)、ユニットテストのルール (`unit/`) |
| `store/` | App Store / Google Play の掲載テキスト |
| `ops/` | 運用・メンテナンスのメモ |
| `marketing/` | LP コンテンツ計画・技術記事 |
| `assets/` | README 等で使う画像 |
| `archive/` | 完了済み・過去の計画書 |

アプリ固有のドキュメントは `apps/web/docs/`・`apps/mobile/docs/` に置く。
