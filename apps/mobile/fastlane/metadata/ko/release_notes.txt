팀에 '랭킹'과 '설정' 탭을 추가하고, 대리 입력을 중심으로 팀 기능을 크게 개선했습니다.

[새로운 기능]
- 팀에 '랭킹' 탭을 추가했습니다. 종목·거리·수영장 종류·성별·기간으로 필터링하여 팀 내 순위와 계영 랭킹을 확인할 수 있습니다. 'WA 포인트로 비교'도 이 탭으로 옮겼습니다
- 팀에 '설정' 탭을 추가했습니다. 팀 정보·초대 코드·팀 기록 색상을 한곳에서 확인하고 변경할 수 있습니다
- 관리자가 멤버를 '비선수'로 설정할 수 있습니다. 비선수는 베스트 타임 목록에서 접혀 표시되며, 대회 엔트리·연습 기록 입력 대상에서 제외됩니다(출결 확인에는 계속 표시됩니다)
- 엔트리 입력에 '베스트 타임 사용' 버튼을 추가했습니다. 대리 입력 화면에서도 각 멤버의 베스트 타임을 확인하며 입력할 수 있습니다
- 관리자용으로 팀의 대회·연습 목록에 '일괄 등록' 버튼을 추가했습니다

[개선]
- 대회 기록 대리 입력을 새롭게 개편했습니다. 종목을 선택하면 선수별 탭에서 입력할 수 있으며, 같은 선수의 두 번째 이후 기록도 추가할 수 있습니다
- 멤버 선택을 칩 형식으로 바꾸고, 성별·그룹별 제목과 '전체 선택'을 추가했습니다
- 연습 로그 대리 입력을 개인 연습 로그와 같은 입력 화면으로 통일했습니다
- 팀 탭에서의 기록·엔트리 입력을 대시보드와 같은 화면으로 통일했습니다. 엔트리한 종목은 기록 입력으로 자동으로 이어집니다
- 팀 대회 기록 목록에서 계영을 4명 단위로 묶어 표시합니다
- 소속 팀이 1개일 때는 팀 탭에서 바로 팀 화면이 열리며, 화면 상단에 팀 이름을 표시합니다
- 캘린더 카드를 탭하면 해당 연습·기록만 표시하고, 상세 화면의 높이를 내용에 맞췄습니다
- 팀 대회·연습의 편집과 삭제는 팀 탭에서 관리자만 할 수 있도록 변경했습니다
- 입력 폼에서 키보드가 입력란을 가리지 않도록 개선하고, 모달의 열림·닫힘 애니메이션을 통일했습니다
- 오류 메시지를 더 알기 쉽게 개선했습니다

[버그 수정]
- 멤버 탭에서 'WA 포인트로 비교'를 눌러도 내용이 표시되지 않던 문제를 수정했습니다
- 연습 로그에서 '새 태그 만들기'를 눌러도 모달이 열리지 않던 문제를 수정했습니다
- 베스트 타임 상세에서 대회명과 비고가 함께 표시되지 않던 문제를 수정했습니다
- 베스트 타임의 'NEW' 배지를 등록일이 아닌 대회일 기준으로 표시하도록 변경했습니다
- 팀 대회 기록 목록에서 계영 첫 번째 영자의 기록이 개인 종목으로 표시되던 문제를 수정했습니다
- 팀 탭에서 기록이나 엔트리를 저장하면 팀 목록까지 돌아가던 문제를 수정했습니다
