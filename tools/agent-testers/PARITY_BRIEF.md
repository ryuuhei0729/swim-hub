# ミッション: mobile と web の差分を揃えた変更（PR #338）を重点的にテストする

まず `AGENT_BRIEF.md` を読み、そこに書かれたツール・ログイン手順・守ること・対象外・最終レポートの形式に
すべて従う。違うのは「確認すること」だけで、ペルソナの `goal` の代わりに下の内容を確かめる。
ペルソナ（端末・文字サイズ・言語・忍耐力）は同じように演じる。

テスト用アカウントは他のテスターと同時に使っている。作る・消すのは自分の `AT-<persona>` のデータだけ。
プロフィール画像の変更、カレンダー連携、プランの購入・変更、AI 読み取り（写真の読み取り）はしない。

## 変わったところ（今回の確認対象）
- ホームのカレンダー: 前月末・翌月初めの薄い日付も押せて、その日の詳細が開く。予定も薄く表示される。
- 日付の詳細（カレンダーの日付を押すと開く）:
  - メニューのある練習は「練習1件のカード」にまとめて表示。練習タイトル・練習メモ・種類（Swim 以外なら Kick/Pull など）が出る。
    練習ごとに共有と削除、メニューごとに共有・編集・削除がある。削除の前には確認が出る。
  - チーム練習・チーム大会には「チームの記録を見る」ボタンがあり、押すとチーム画面の予定タブでその詳細が開く。
  - チーム練習には、自分のログがあっても出欠ボタンが出る。チーム練習では自分のメニューだけが表示される。
  - 大会記録の詳細では、タイムの横にベスト判定のバッジ（初・ベストとの差）、距離別 Lap の表（200m 以上なら 100m などの列も）が出る。
  - エントリー済みの大会では、エントリー1件ずつに削除（確認つき）があり、大会の画像が出る。
  - 大会カードの本体を押しても詳細は閉じない。
- ホームの「次の大会」カード: エントリーした種目の下に「エントリー 56.20」のようにエントリータイムが出る。
- 練習タイムの入力画面: 入力の途中でキャンセル・戻るを押すと、破棄してよいかの確認が出る。
- 大会の入力: 「場所」に入力すると、過去に使った場所の候補が出る。
- 練習ログテンプレートの管理画面（マイページから辿れる）: 作成・編集にタグ欄がある。
- チーム画面: お知らせ一覧の項目を押すと全文が読める。メンバー一覧をグループで表示すると、グループ内は年上が先に並ぶ。
- マイページ: 規約・プライバシーポリシーと並んで「お問い合わせ」「タイムレベル判定」のリンクがある（ブラウザが開けば OK。開いた先の中身は対象外）。
- 新規登録画面（ログインせずに「新規登録」の画面を開くだけ。**登録は実行しない**）: 性別と生年月日の入力欄がある。

## 確認すること（操作はおよそ 50 回）
1. ログイン前に、ようこそ画面から新規登録の画面を開き、性別・生年月日の欄があるか、大きな文字で崩れないかを見る。
   何も送信せずに戻り、ログインする。
2. ホームの「次の大会」カードにエントリータイムが出ているか（エントリーした大会が無ければ「無い」と記録して次へ）。
3. ホームのカレンダーで、前月末・翌月初めの薄い日付を押してみる。詳細が開くか、その日の予定が出るか。
   月を切り替えて同じことを確かめる。
4. 今日の日付で練習を1件追加する（タイトルとメモに `AT-<persona>`、メニュー2つ、片方は種類を Kick にしてタイムを入れる）。
   - タイム入力の画面で、何本か入れてから「キャンセル」/ 戻るを押し、確認が出るか。「破棄しない」を選ぶと入力が残るか。
   - 保存後、日付の詳細で「練習1件のカード」になっているか、タイトル・メモ・Kick 表示・共有ボタンがあるか。
   - メニュー1つを削除（確認が出るか）→ 練習そのものを削除（確認が出るか）。削除後に練習が残らないか。
5. 大会を1件追加する（大会名に `AT-<persona>`、日付は今日）。「場所」の欄で過去の場所の候補が出るか。
   200m の種目で 50m ごとのラップを入れて記録を保存し、日付の詳細でベストバッジと Lap の表（列・見出し）を確認する。
   確認できたらこの大会を削除する。
6. チームタブで、お知らせ（🔔 など）を開き、項目を押して全文が読めるか。メンバー一覧をグループ表示にして並び方を見る。
   予定タブのチーム練習・チーム大会がカレンダーにあれば、その日の詳細から「チームの記録を見る」を押し、チーム画面で詳細が開くか。
7. マイページの「お問い合わせ」「タイムレベル判定」を押して、ブラウザ（またはアプリ内ブラウザ）が開くか。戻ってアプリが正常か。
8. マイページから練習ログテンプレートの管理を開き、テンプレートを1件作る（名前に `AT-<persona>`、タグを1つ付ける）。
   一覧に出るか、編集してタグを外せるか。最後にそのテンプレートを削除する。
9. この端末でのレイアウト: 上の画面すべてで、文字の切れ・はみ出し、日付詳細の右上のアイコンの重なり・押しにくさ、
   Lap の表の詰まり、確認ダイアログのボタンの見切れ、大きな文字サイズ・ダークテーマでの見え方、翻訳（日本語以外のとき）。
