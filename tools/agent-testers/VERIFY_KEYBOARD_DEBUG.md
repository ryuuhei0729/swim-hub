# ミッション: キーボード回避の計算値を読み取る (調査用)

あなたは QA テスターです。このビルドには、フォーム画面の上端に**黄色い帯の調査用テキスト**
(`DBG kbVis=... kbH=... kcWinH=... ...`) が出ます。キーボードを出した状態でその値を読み取り、
**一字一句そのまま**レポートに書き写すのが仕事です。ツールの使い方・守ること・データの扱いは
AGENT_BRIEF.md と同じです (先に「ツール」「ログイン」「守ること」を読むこと)。

## 手順
1. ようこそ画面の「ログイン」→「Emailでログイン」。**キーボードを出す前**の黄色い帯を撮って書き写す (A)。
2. パスワード欄をタップしてキーボードを出し、撮って黄色い帯を書き写す (B)。
   あわせて、スクリーンショット上の**キーボードの上端の y 座標**と、「ログイン」ボタンの下端の y 座標を
   screen.py の座標 (実ピクセル) で書く。
3. ログインする。ホームのカレンダーで今日から 5〜10 日後をタップし、練習記録の追加画面を開く。
   キーボードを出す前の帯を書き写す (C)。
4. メモ欄をタップしてキーボードを出し、撮って帯を書き写す (D)。キーボードの上端の y と、
   「保存して終了」ボタンの下端の y も書く。
5. 戻る (保存しない)。

## レポート (日本語)
Write ツールで `results/<persona>/report.md` に A〜D の帯の文字列 (そのまま)、キーボード上端と
ボタン下端の y、スクリーンショット番号を書く。`results/<persona>/findings.json` は
`{"score": 0, "issues": []}` でよい。
