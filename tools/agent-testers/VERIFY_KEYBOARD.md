# ミッション: Android でフォームがキーボードを避けるかを確かめる

あなたは QA テスターです。入力欄をタップしてキーボードが出たとき、**入力中の欄と画面下のボタンが
キーボードに隠れないか**を確かめます。探索的なテストはしません。ツールの使い方・守ること・データの扱いは
AGENT_BRIEF.md と同じです (先に「ツール」「ログイン」「守ること」を読むこと)。

**キーボードが表示された状態のスクリーンショット**が判定の根拠です。入力欄をタップしてキーボードが
出たことを確認してから撮ること (出ていなければもう一度タップ)。文字の入力はしなくてよい。

## 確認 1: ログイン画面
1. ようこそ画面の「ログイン」→「Emailでログイン」。
2. パスワード欄をタップし、キーボードが出た状態で撮る。
   → 「ログイン」ボタンがキーボードより上に見えるか。
3. メールアドレスとパスワードを入力し、キーボードの確定キーでログインする。

## 確認 2: 練習記録の作成画面 (ヘッダーのある画面)
1. ホームのカレンダーで今日から 5〜10 日後をタップし、練習記録の追加画面を開く。
2. **一番下の入力欄 (メモ)** をタップし、キーボードが出た状態で撮る。
   → メモ欄がキーボードより上に見えるか。画面下の「保存して終了」「次に進む」がキーボードより上に見えるか。
   → キーボードと画面下のボタンの間に、不自然に大きな空白 (目安: ボタン 2 個分以上) が無いか。
3. 戻る (保存しない)。

## 確認 3: 大会記録の作成画面
1. ホームのカレンダーで今日から 5〜10 日後をタップし、大会記録 (または大会) の追加画面を開く。
2. 画面の下の方にある入力欄 (メモなど) をタップし、キーボードが出た状態で撮る。
   → 入力欄と画面下のボタンがキーボードより上に見えるか。不自然に大きな空白が無いか。
3. 戻る (保存しない)。

## 確認 4: 下から出るシート (モーダル)
1. ホームの「Best Time」の右下「一括入力」を押す (シートが下から出る)。
2. シートの中の**下の方の入力欄**をタップし、キーボードが出た状態で撮る。
   → その入力欄とシートのボタン (保存など) がキーボードより上に見えるか。不自然に大きな空白が無いか。
3. 何も保存せずに閉じる。

## レポート (日本語)
