## 確認 1: ログイン画面のキーボード
1. ようこそ画面の「ログイン」→「Emailでログイン」。
2. メールアドレス欄をタップしてメールアドレスを入力する。
3. **キーボードの確定キー**を押す (Android: `adb shell input keyevent KEYCODE_ENTER` / iOS: `bash scripts/ios/gesture.sh enter`)。
   → パスワード欄に移るか確認 (スクリーンショット)。
4. パスワードを入力し、**キーボードを開いたまま**スクリーンショットを撮る。
   → ログインボタンが見えているか、または画面を上にスクロールすると見えるかを確認 (スクロールして確かめる)。
5. **キーボードの確定キー**を押す。→ ログインしてホームに進むか確認。
   進まなければ、ログインボタンを 1 回タップして進むかも確認する。
